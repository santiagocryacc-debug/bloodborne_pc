# Launcher Text

The interface stays in English. Use Title Case for every visible label and button, including short words: `Preset To Apply`.

Keep technology names and acronyms uppercase: `XESS`, `DLSS`, `FSR`, `AMD`, `NVIDIA`, `CPU`, `GPU`, `PC`, `UI`, `FPS`, `FIFO`, `TAA`, `GTAO`.

Do not add tooltips, hover descriptions, inline help, explanatory footnotes, or instructions beneath options. Keep operation feedback brief, such as `Settings Saved` or `Preset Applied`.

Do not use hyphens in labels. Remove parenthesized text entirely, including qualifiers such as Auto or Experimental. For example, display `FSR` and `Upscale Before Post Processing`.

Apply these rules only to display text. Preserve configuration keys, environment variables, internal values, filenames, paths, and settings behavior.
